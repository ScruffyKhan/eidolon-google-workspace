Eidolon Google Workspace

Privacy policy

This policy describes the private Google Workspace integration operated by Elliot Carter. It takes effect when published.

Google information accessed

With the account owner's consent, the integration can read Gmail messages and metadata, calendars and events, Google Drive files and metadata, Google Docs documents, and Google Sheets spreadsheets. Access is read-only. The integration does not request permission to send email, modify or delete Google content, or share files.

Purpose and processing

Google information is used to provide owner-requested assistant functions, such as searching, summarizing information and supporting planning. Retrieved information may be included in assistant conversations and processed by AI inference services selected by the operator. It is therefore not accurate to describe all processing as exclusively local.

The integration does not sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models. Any transfer to a service provider is limited to providing or improving the owner-facing features of this integration and must comply with the Google API Services User Data Policy.

Eidolon Google Workspace's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

OAuth credentials are stored in access-restricted files on the operator's system, not in this public website or its source repository. Retrieved information may remain in assistant conversation history, task artifacts, logs or configured service-provider records. Retention depends on the operator's configuration and the applicable service-provider terms; this policy does not promise immediate or automatic deletion of every copy.

Revocation and deletion requests

The account owner can revoke future Google access through Google Account third-party connections. Revocation stops future authorized access but does not automatically remove information already retained in conversations or other records. Contact the operator at ecarter1117@gmail.com to request review and deletion of retained integration data. Requests are handled subject to the operator's control over those records and applicable legal or service-provider retention requirements.

This website

These static information pages contain no application analytics, advertising scripts, login forms or Google credentials. GitHub Pages hosts the site. GitHub documents that it logs visitors' IP addresses for security purposes; see the GitHub Privacy Statement.

Contact and policy changes

Operator: Elliot Carter. Contact: ecarter1117@gmail.com. Material changes to this policy will be published on this page. A change to Google access permissions requires a separate authorization decision; it is not granted by editing this policy.
